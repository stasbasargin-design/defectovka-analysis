# Как добавить исходные Excel-файлы

Репозиторий уже создан: https://github.com/stasbasargin-design/defectovka-analysis

Шесть исходных XLSX в этом репозитории **пока отсутствуют**. Они доступны в архиве `defectovka-analysis-github-ready.zip`, выданном в чате.

## Загрузка

1. Скачайте и распакуйте ZIP из чата на компьютер.
2. В GitHub откройте репозиторий и нажмите **Add file → Upload files**.
3. В загружаемых файлах должна сохраниться директория `data/raw/`. Удобнее загрузить весь подготовленный пакет с локального компьютера через Git:
   ```bash
   git clone https://github.com/stasbasargin-design/defectovka-analysis.git
   cd defectovka-analysis
   ```
4. Скопируйте шесть файлов из распакованной папки `data/raw/` в одноимённую папку клона, **не изменяя имена и содержимое**.
5. Выполните:
   ```bash
   git add data/raw
   git commit -m "data: add six original XLSX snapshots"
   git push
   ```
6. Откройте вкладку **Actions**. После загрузки должны выполниться все 11 тестов и аудит источников.

Внимание: файлы содержат коммерческие и потенциально персональные данные. Репозиторий должен оставаться Private. Не загружайте пароли, токены или дампы производственной БД.
